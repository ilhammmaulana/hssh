Installation

Single static binary compiled for all major operating systems.

Method 1: Universal Shell Script Recommended
curl -fsSL https://raw.githubusercontent.com/ilhammmaulana/hssh/main/install.sh | bash
Method 2: Ubuntu / Debian APT Repository
curl -sS https://ilhammmaulana.github.io/hssh/apt/KEY.gpg | sudo gpg --dearmor -o /etc/apt/trusted.gpg.d/hssh.gpg && echo "deb [arch=amd64,arm64] https://ilhammmaulana.github.io/hssh/apt stable main" | sudo tee /etc/apt/sources.list.d/hssh.list && sudo apt update && sudo apt install hssh
Method 3: Direct .deb Package Download
curl -LO https://github.com/ilhammmaulana/hssh/releases/latest/download/hssh_linux_amd64.deb && sudo apt install ./hssh_linux_amd64.deb

Terminal Installer (Apple Silicon M1/M2/M3/M4 & Intel):

curl -fsSL https://raw.githubusercontent.com/ilhammmaulana/hssh/main/install.sh | bash

Auto-detects Darwin architecture and sets up native permissions.

PowerShell One-Liner (Run as standard user):

irm https://raw.githubusercontent.com/ilhammmaulana/hssh/main/install.ps1 | iex

Installs hssh.exe to $HOME\bin and registers it in User PATH.

Compile directly from Go repository:

go install github.com/ilhammmaulana/hssh@latest

Requires Go 1.22+ installed on your host system.

Quickstart

Set up your first host and passwordless access in three steps.

STEP 01

Launch Dashboard

Run the executable without flags to enter the interactive TUI menu.

hssh
STEP 02

Add Server

Pass alias, IP, username, and port. Generates key and copies automatically.

hssh add prod 103.20.10.42 deploy 22
STEP 03

Connect

Connect directly using the alias without retyping passwords or host addresses.

hssh prod

Command Reference

Overview of all available subcommands and flags.

Command Arguments Action
hssh — Opens interactive terminal management dashboard.
hssh list — Lists all configured servers with concurrent TCP ping latency.
hssh list-fast — Immediate host table listing without executing network ping checks.
hssh <alias> <alias> Direct connection shortcut to target server.
hssh add [alias] [ip] [user] [port] Adds new host and initiates key generation/copying.
hssh ping [alias] Runs round-trip TCP dial to measure server port latency.
hssh test [alias] Validates passwordless login status in non-interactive batch mode.
hssh edit [alias] Interactively updates host IP, username, port, or environment tags.
hssh copy-key [alias] Copies public key to target machine with universal fallback piping.
hssh backup — Creates manual timestamped snapshot of ~/.ssh/config.
hssh remove [alias] Safely removes entry with automated pre-delete backup.

Security Specifications

How HSSH handles cryptographic keys, permissions, and network boundaries.

One-Way Authentication

Only public keys (id_ed25519.pub) are ever sent to remote hosts. Private keys remain exclusively on your local workstation. Possessing a public key gives the remote server zero capability to connect back or reverse-authenticate into your machine.

Strict Local Permissions

HSSH enforces POSIX file permission standards on all operations: 0700 on ~/.ssh directory, and 0600 on ~/.ssh/config and private keys, preventing unauthorized read access by other local processes.

Pre-Write Safety Backups

Prior to modifying or deleting records, HSSH clones ~/.ssh/config to a timestamped backup (~/.ssh/config.bak.<timestamp>) preventing accidental data corruption or loss.

Standard OpenSSH File Format

No proprietary database formats or hidden state. All host directives are stored natively in standard OpenSSH syntax. Standard terminal tools, VS Code SSH plugins, and Ansible continue working transparently.

Technical Documentation

Detailed guidance for developers and systems engineers.

Windows OpenSSH Environment Handling

On Windows 10/11, native OpenSSH is stored in C:\Windows\System32\OpenSSH\ssh.exe. While Linux distributions ship with ssh-copy-id, Windows does not.

HSSH solves this by detecting the runtime environment. On Windows, it executes key installation directly via an authenticated SSH sub-shell: 

ssh -p 22 user@host "mkdir -p ~/.ssh && chmod 700 ~/.ssh && echo '<pubkey>' >> ~/.ssh/authorized_keys && chmod 600 ~/.ssh/authorized_keys"

TCP Latency Measurement

When executing hssh list, HSSH launches concurrent goroutines across each configured entry to perform a fast non-blocking TCP socket dial: 

net.DialTimeout("tcp", net.JoinHostPort(host, port), 1200*time.Millisecond)

This bypasses ICMP blocks frequently present in cloud environments (AWS Security Groups, DigitalOcean Firewalls) and verifies that the SSH port itself is accepting connections.

Tags and Environment Labels

Tags are persisted safely inside ~/.ssh/config as prefixed comments preceding each Host directive: 

# tags: prod,api,backend
Host prod-api
    HostName 103.20.10.42
    User deploy
    Port 22
    IdentityFile ~/.ssh/id_ed25519

This format ensures full compatibility with native OpenSSH parsers while allowing HSSH to categorize hosts across different clusters and environments.
